# SiteWorksStudio

Публичный статический сайт SiteWorksStudio. CRM, серверные функции и секреты сюда не загружаются.

Публикация: GitHub → Settings → Pages → Deploy from a branch → main → / (root).

Домен siteworksstudio.ru переключать на GitHub Pages только после проверки временного адреса.

Форма заказов использует отдельный endpoint Tuqo Forms; реальную доставку заявки необходимо проверить.

SiteWorksStudio OS работает отдельно: https://siteworksstudio-os-layero-free.layero.app/
