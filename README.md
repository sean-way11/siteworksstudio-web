# SiteWorksStudio

Публичный статический сайт SiteWorksStudio. CRM, серверные функции и секреты сюда не загружаются.

Публикация: GitHub → Settings → Pages → Deploy from a branch → main → / (root).

Домен `siteworksstudio.ru` указывает на GitHub Pages. 14 ноября после разрешения владельца экран технических работ снят; сайт снова открыт.

Форма заказов использует Supabase Edge Function `sws-public-site-lead`; контрольная заявка 14 ноября дошла до заказа в OS. Доставка Telegram-уведомления не подтверждена.

SiteWorksStudio OS работает отдельно: https://os.siteworksstudio.ru/

Старые пути `/admin`, `/admin/` и `/admin.html` переводят на рабочую панель OS. Адрес Layero больше не используется для входа.

После разрешения владельца изменения опубликованы в ветке `main` репозитория `sean-way11/siteworksstudio-web`, коммит GitHub `9934dfa5b493d8751b963580dda8f64c350bff1b`. В локальном браузере все шесть страниц показали содержимое и ширину 390 px без переполнения. После обновления GitHub Pages на `siteworksstudio.ru` главная, услуги, портфолио, форма, «О студии» и 404 открылись без экрана обслуживания; на форме антиспам-поле скрыто и загружается новая версия `brief.js`. ## Подготовка расширения портфолио — 14 ноября 2026

По уточнению владельца о прежнем обновлении проверены сохранённые версии. Актуальная главная страница `portfolio.html` показывала семь карточек, а NEXUS, Velora и Aurora вели только к форме заказа. Отдельных открываемых сайтов этих концептов в найденных исходниках не было. Опубликованный ранее адрес `portfolio.siteworksstudio.ru` в браузерной проверке не открылся; это не доказывает состояние самого Cloudflare-проекта.

В рабочую копию добавлена проверенная версия digital-портфолио из `../../siteworksstudio-portfolio/digital-portfolio-upgrade-2026-11-07/` в `digital-portfolio/` вместе с изображениями; исходник оставлен на месте. На основной странице портфолио добавлены три обложки и переходы в полное digital-портфолио и сразу к фильтру Reels/Shorts. Для NEXUS, Velora и Aurora созданы отдельные адаптивные демонстрационные страницы в `demo/`; ссылки на них добавлены к карточкам портфолио, а для NEXUS и Velora также на главную. Страницы прямо обозначены концептами, Velora не обещает работающую оплату. Видео-карточки в digital-портфолио остаются визуальными концепциями, а не готовыми роликами.

Playwright открыл портфолио, три демо-страницы и digital-портфолио при ширинах 390 и 1280 px без горизонтального переполнения; изображения обложек загружаются после прокрутки.
