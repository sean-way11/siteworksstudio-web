Видеотека для школы

Каталог видео и презентаций по ОБЗР для 8–11 классов.

Задача

Собрать в одном месте материалы по ОБЗР, чтобы их можно было найти по теме и подготовить к уроку.

Как устроен каталог

  • В разделе видео можно искать по названию или теме, например по запросу «эвакуация».
  • В разделе презентаций можно искать по названию и выбрать класс.
  • Для материалов Краснодарского края собраны ссылки на региональные источники. На сайте также есть инструкция по сохранению видео для показа без интернета.
